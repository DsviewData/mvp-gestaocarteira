📁 Instruções de Uso

Este dashboard requer 4 arquivos HTML na mesma pasta:

✓ dashboard_integrado_completo.html (este arquivo)

✓ visão_geral.html

✓ visao_alerta_prechurn_completo.html

✓ visao_perda_churn_completo.html

Como configurar:

  1. Baixe todos os 4 arquivos HTML
  2. Coloque-os na mesma pasta/diretório
  3. Abra este arquivo no navegador
  4. Os dashboards serão carregados automaticamente nas abas

⚠️ Atenção: Se você está vendo esta mensagem, os arquivos não estão na mesma pasta!
