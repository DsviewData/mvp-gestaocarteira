📋 Instruções de Uso

Este dashboard requer 9 arquivos HTML na mesma pasta:

✓ login.html

✓ dashboard.html (este arquivo)

✓ visão_geral.html

✓ visao_alerta_prechurn_completo.html

✓ visao_perda_churn_completo.html

✓ painel_perda_risco_final.html

✓ painel_perda_risco_novo.html

✓ dashboard_historico_churn_completo.html

✓ dashboard_clientes_recuperados.html

Como configurar:

  1. Baixe todos os 9 arquivos HTML
  2. Coloque-os na mesma pasta/diretório
  3. Abra o arquivo login.html no navegador
  4. Faça login e os dashboards serão carregados automaticamente

⚠️ Atenção: Se você está vendo esta mensagem, os arquivos não estão na mesma pasta!
